# Unit

The unit of the cost. Can be CREDITS or DOLLARS. Note: DOLLARS unit only supports PAYG plan.

## Example Usage

```python
from leonardo_ai_sdk.models.shared import Unit

value = Unit.CREDITS
```


## Values

| Name      | Value     |
| --------- | --------- |
| `CREDITS` | CREDITS   |
| `DOLLARS` | DOLLARS   |
