# UniversalUpscalerUltraStyle

The ultra style to upscale images using universal upscaler with. Can not be used with upscalerStyle.

## Example Usage

```python
from leonardo_ai_sdk.models.shared import UniversalUpscalerUltraStyle

value = UniversalUpscalerUltraStyle.ARTISTIC
```
