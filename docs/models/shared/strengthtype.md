# StrengthType

Strength type for the controlnet. Can only be used for Style, Character and Content Reference controlnets.

## Example Usage

```python
from leonardo_ai_sdk.models.shared import StrengthType

value = StrengthType.LOW
```


## Values

| Name    | Value   |
| ------- | ------- |
| `LOW`   | Low     |
| `MID`   | Mid     |
| `HIGH`  | High    |
| `ULTRA` | Ultra   |
| `MAX`   | Max     |
