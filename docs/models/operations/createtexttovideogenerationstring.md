# CreateTextToVideoGenerationString

The model to use for the video generation. Defaults to MOTION2 if not specified.


## Values

| Name           | Value          |
| -------------- | -------------- |
| `MOTION2`      | MOTION2        |
| `VEO3`         | VEO3           |
| `MOTION2_FAST` | MOTION2FAST    |
| `VEO3_FAST`    | VEO3FAST       |
